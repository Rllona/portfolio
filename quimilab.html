Quimilab

About the project

QuimiLab is an educational video game developed in collaboration with the Spanish university Universidad Rey Juan Carlos. Its main goal is to help chemistry students reinforce their knowledge of laboratory safety through an interactive and engaging experience.

Roles

Programming, Level Design, Script Writing and Music & Sound Effects

Timeline

September 2023 - July 2024

Tools

Unity, Github, MySQL, Audacity.

Game Design

QuimiLab falls into the Serious Game category. It is designed to be an enjoyable game while still maintaining its main educational purpose.

The game takes place in a chemistry lab, similar to those found in university facilities. The objective is to complete a series of tasks and experiments while consistently following laboratory safety procedures.

Characteristics

  • 3D
  • First and third-person gameplay
  • Level-based progression
  • Character customization
  • Chemistry simulation
  • Playable in a web browser

Development

The team followed an agile methodology to organize the project, dividing the development process into several sprints and iteratively delivering new releases throughout the project. Each release was presented to the university's professors, allowing the team to gather feedback and adjust the game according to their requirements and preferences. Unity was chosen as the game engine.

Implemented features:

  • Particle system
  • Shaders
  • Custom collision system for non-convex rigidbodies
  • Input system
  • Connection to an external database

Script Writing

The game's script was designed to use a casual and relatable tone, incorporating humor and small jokes to make the experience more appealing to younger audiences. The goal was to make the educational content feel more engaging and entertaining, encouraging students to enjoy the process while completing the game.

Outcomes

  • Developed and launched a complete educational game that is currently being used by real chemistry students.
  • Learned how to develop a game based on a client's requirements and translate them into engaging game mechanics.
  • Developed both a game and a chemistry simulator as part of the same product.
